# Material You 风格 UI 升级 PRD

**文档版本**: v1.0  
**创建日期**: 2025-10-30  
**产品**: Android ADB 调试工具  
**目标**: 将应用从传统 UI 升级为 Material You 设计语言

---

## 一、项目背景与目标

### 1.1 背景
当前应用采用传统的侧边栏导航设计，视觉风格较为基础，缺乏现代感和个性化特征。Material You 作为 Google 最新设计语言，强调个性化、适应性和表达力，能显著提升用户体验。

### 1.2 核心目标
- **视觉现代化**: 提升应用整体视觉品质，符合 2025 年设计趋势
- **交互流畅性**: 优化操作流程，减少用户认知负担
- **个性化体验**: 引入动态配色系统，增强用户情感连接
- **一致性**: 统一全局设计语言，建立清晰的视觉层级

---

## 二、Material You 设计原则应用

### 2.1 色彩系统
**设计策略**:
- **动态主题色**: 支持用户自定义主题色，或基于系统壁纸提取配色
- **色彩角色定义**: 建立 Primary、Secondary、Tertiary、Error、Surface 等色彩角色
- **明暗模式**: 完整支持浅色/深色主题，自动或手动切换
- **色彩层级**: 通过色彩深浅表现内容层级和状态变化

**交互考量**:
- 主题色切换时提供平滑过渡动画（300ms）
- 暗黑模式切换保留用户上下文，避免闪烁

### 2.2 形状系统
**设计策略**:
- **统一圆角**: 采用 Material You 标准圆角体系
  - 小圆角: 8dp（按钮、输入框）
  - 中圆角: 12dp（卡片、列表项）
  - 大圆角: 16dp（对话框、底部抽屉）
  - 超大圆角: 28dp（悬浮按钮、特殊强调元素）
- **形状语义**: 通过形状变化传达交互状态和内容性质

### 2.3 排版系统
**设计策略**:
- 采用 Material You 标准字阶系统（Display、Headline、Title、Body、Label）
- 重要信息使用更大字号和更重字重
- 保持阅读舒适的行高和字间距（行高 1.5倍字号）

### 2.4 微动效
**交互原则**:
- 所有状态变化必须有视觉反馈
- 过渡动画遵循缓动曲线（ease-out 为主）
- 动画时长控制在 100-300ms 之间
- 复杂动画采用错峰执行，避免性能问题

## 三、整体布局设计

### 3.1 布局架构调整

**当前问题**:
- 侧边栏固定 200px，在小屏幕下空间利用率低
- 内容区域缺乏呼吸感，元素过于紧凑
- 层级关系不够清晰

**优化方案**:

#### 导航模式
**方案 A：侧边栏导航 Rail（推荐）**
- **适用场景**: 平板、桌面端
- **视觉特征**:
  - 侧边栏宽度 72-80dp（仅图标）
  - Hover 时显示文字标签（浮动提示）
  - 选中项使用 Pill 形状指示器
  - 支持展开为 Navigation Drawer（280dp）
- **优势**: 节省横向空间，聚焦内容区

**方案 B：导航抽屉（次选）**
- 默认收起，点击按钮展开
- 展开宽度 280dp
- 半透明遮罩覆盖内容区

#### 内容区布局原则
- **留白**: 顶部/左右边距最小 24dp，底部 16dp
- **卡片化**: 功能模块封装在 Surface 卡片中，带微投影
- **网格系统**: 采用 8dp 基准网格，所有间距为 8 的倍数
- **响应式**: 
  - 窗口宽度 < 840dp: 单列布局
  - 窗口宽度 840-1200dp: 双列布局
  - 窗口宽度 > 1200dp: 三列或自适应布局

## 四、核心页面交互设计

### 4.1 首页（快捷功能页）

**信息架构**:
```
顶部栏（64dp 高）
├─ 设备选择器（左侧，可展开下拉）
├─ 连接状态指示（点状指示器 + 文字）
└─ 操作区（右侧，主题切换、设置入口）

内容区
├─ 功能卡片网格（Grid）
│   ├─ 每个卡片 120dp × 120dp
│   ├─ 图标 + 标题 + 副标题（可选）
│   ├─ Hover 时浮起（elevation 提升）
│   └─ 点击时水波纹反馈
└─ 快速操作区（底部）
    └─ 悬浮操作按钮（FAB）- 用于高频操作
```

**交互细节**:
1. **设备选择器**
   - 默认显示当前设备名称和型号
   - 点击展开显示所有已连接设备列表
   - 支持搜索和过滤
   - 无设备时显示引导：拖拽 APK 或点击设置 ADB

2. **功能卡片**
   - 分组显示：应用管理、系统操作、开发调试、文件传输
   - 卡片支持自定义顺序（长按拖拽）
   - 高频功能可固定到顶部
   - 状态反馈：
     - 执行中：进度环
     - 成功：绿色勾 + 提示
     - 失败：红色感叹号 + 错误信息

3. **视觉层级**
   - 背景：Surface 色（纯色或微渐变）
   - 卡片：Surface1 色（略浅/深于背景）
   - 选中/Hover：Surface2 色
   - 分隔：使用间距而非线条

### 4.2 文件管理页

**信息架构**:
```
顶部导航栏（56dp 高）
├─ 路径面包屑（可点击跳转）
├─ 搜索框（展开式，右对齐）
└─ 视图切换（列表/网格）+ 更多操作

文件列表区
├─ 列表模式
│   ├─ 图标（24dp）+ 文件名 + 大小 + 修改时间
│   ├─ 分组标签（今天、昨天、更早...）
│   └─ 手势：左滑显示删除、右滑显示更多
└─ 网格模式
    ├─ 卡片（160dp × 180dp）
    ├─ 缩略图 + 文件名
    └─ 选择模式：长按进入

底部操作栏（浮动，选中时出现）
├─ 已选数量提示
└─ 操作按钮组（下载、删除、分享...）
```

**交互细节**:
1. **路径导航**
   - 面包屑每级可点击，返回上级目录
   - 当前路径高亮显示
   - 路径过长时中间用省略号，点击展开完整路径
   - 支持直接输入路径跳转

2. **文件操作**
   - **拖拽上传**: 
     - 拖入时显示全屏虚线框 + 提示文案
     - 放下时显示上传进度卡片（支持多文件）
     - 上传完成后自动刷新列表并高亮新文件
   
   - **下载文件**:
     - 单文件：点击即下载，底部 Snackbar 显示进度
     - 多文件：批量选择后点击下载，显示下载队列

   - **预览**:
     - 图片/视频：点击卡片直接预览（全屏 Gallery）
     - 文本文件：右键菜单 → 预览（底部抽屉）
     - 不支持格式：显示文件信息

3. **视觉反馈**
   - 空状态：插画 + 引导文案（"拖入文件开始传输"）
   - 加载状态：骨架屏（避免白屏）
   - 错误状态：错误图标 + 错误信息 + 重试按钮

4. **性能优化考虑**
   - 列表虚拟滚动（只渲染可见区域）
   - 图片懒加载和缓存
   - 大文件夹分页加载（每页 100 项）

### 4.3 LogCat 日志页

**信息架构**:
```
顶部工具栏（56dp 高）
├─ 日志级别筛选（Chips，可多选）
├─ 搜索框（支持正则）
└─ 操作：清空、导出、暂停/继续

日志内容区
├─ 虚拟滚动列表
├─ 日志条目卡片化（而非纯文本）
│   ├─ 时间戳（灰色，小字）
│   ├─ 级别标签（彩色 Chip）
│   ├─ Tag（粗体）
│   └─ 消息内容（可展开）
└─ 自动滚动到底部（可禁用）

侧边过滤面板（可展开）
├─ 按应用包名过滤
├─ 按 Tag 过滤
└─ 自定义过滤规则
```

**交互细节**:
1. **日志级别筛选**
   - Verbose、Debug、Info、Warn、Error、Fatal
   - 多选 Chips，选中高亮
   - 级别用颜色区分：灰、蓝、绿、橙、红、紫
   - 实时过滤，无需刷新

2. **搜索体验**
   - 输入时实时高亮匹配项
   - 支持跳转到上一个/下一个匹配
   - 搜索历史记录（最近 10 条）
   - 支持正则表达式开关

3. **日志展示**
   - 长日志折叠显示，点击展开
   - 支持复制单条或多条日志
   - 支持选中范围导出
   - 关键词高亮（Error、Exception...）

## 五、通用组件设计规范

### 5.1 按钮系统

**层级分类**:
1. **主要按钮（Filled Button）**
   - 使用场景：主要操作（确认、保存、提交）
   - 视觉：Primary 色填充，白色文字
   - 尺寸：高 40dp，内边距 24dp 横向

2. **次要按钮（Outlined Button）**
   - 使用场景：次要操作（取消、返回）
   - 视觉：边框 + Primary 色文字
   - 尺寸：高 40dp

3. **文字按钮（Text Button）**
   - 使用场景：低优先级操作
   - 视觉：无边框，仅文字

4. **图标按钮（Icon Button）**
   - 使用场景：工具栏操作
   - 尺寸：48dp × 48dp（含点击区域）

**状态设计**:
- Normal: 默认样式
- Hover: 背景色加深 8%
- Pressed: 背景色加深 12% + 水波纹
- Disabled: 透明度 38%，不可交互

### 5.2 输入框

**设计规范**:
- 高度：56dp
- 圆角：4dp（顶部）
- 底部指示线：2dp，聚焦时变为 Primary 色
- 标签浮动：未输入时居中，输入后浮动到顶部
- 辅助文字：12sp，灰色，位于底部

**状态**:
- 默认：灰色边框
- 聚焦：Primary 色边框 + 阴影
- 错误：Error 色边框 + 错误提示
- 禁用：灰色背景，禁止输入

### 5.3 对话框

**结构**:
```
对话框（最小宽度 280dp）
├─ 图标（可选，顶部居中，48dp）
├─ 标题（24sp，粗体）
├─ 内容区（16sp，滚动）
└─ 操作栏（右对齐）
    ├─ 次要按钮（左侧）
    └─ 主要按钮（右侧）
```

**动画**:
- 进入：从底部滑入 + 淡入（250ms）
- 退出：淡出（200ms）
- 背景遮罩：黑色 50% 透明度

### 5.4 通知反馈

**Snackbar（底部通知条）**:
- 位置：底部 16dp
- 宽度：最大 672dp，居中显示
- 高度：48-68dp（单行/双行）
- 自动消失：4 秒
- 支持操作按钮（最多 1 个）

**Toast（轻提示）**:
- 用于简单成功/失败提示
- 2 秒自动消失
- 半透明黑色背景，白色文字

## 六、动效设计指南

### 6.1 页面转场
- **淡入淡出**: 简单页面切换，200ms
- **共享元素过渡**: 卡片展开到详情页，300ms
- **侧滑**: 返回操作，250ms

### 6.2 元素动效
- **列表项进入**: 从上到下依次淡入，每项延迟 50ms
- **卡片 Hover**: 提升 elevation（2dp → 8dp），150ms
- **按钮点击**: 水波纹扩散，300ms
- **数据刷新**: 圆形进度指示器旋转

### 6.3 状态反馈
- **成功**: 绿色勾动画（路径绘制）
- **失败**: 红色感叹号 + 震动效果
- **加载**: 循环进度条或骨架屏

## 七、响应式适配

### 7.1 断点定义
- **Compact（< 600dp）**: 手机竖屏
- **Medium（600-840dp）**: 手机横屏、小平板
- **Expanded（> 840dp）**: 平板、桌面

### 7.2 布局适配策略
- Compact: 底部导航栏 + 单列内容
- Medium: 侧边导航 Rail + 单/双列内容
- Expanded: 侧边导航 Rail + 双/三列内容

### 7.3 字体缩放
- 支持系统字体缩放（100%-200%）
- 保持布局不错乱
- 重要信息优先显示

---

## 八、无障碍设计

### 8.1 视觉无障碍
- **对比度**: 所有文字对比度 ≥ 4.5:1（WCAG AA 标准）
- **色盲友好**: 不仅依靠颜色传达信息，配合图标和文字
- **焦点指示**: 键盘导航时清晰的焦点框（2dp，Primary 色）

### 8.2 操作无障碍
- **触摸目标**: 最小 48dp × 48dp
- **语音描述**: 所有图标按钮添加语义化标签
- **键盘操作**: 支持 Tab 导航和快捷键
